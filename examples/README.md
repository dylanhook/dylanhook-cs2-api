# Examples

These are complete scripts built around useful features. Use them as a starting
point, then use the API reference for individual functions and edge cases.

| Example | Focus |
| --- | --- |
| [Watermark](watermark.md) | FPS, latency, map, clock and dragging |
| [Keybind list](keybind_list.md) | Active binds, animation and dynamic sizing |
| [Spectator list](spectator_list.md) | Spectators, animation and dragging |
| [Skeleton ESP](skeleton_esp.md) | Model bones, hitbox chains and world-to-screen |
| [Bomb timer](bomb_timer.md) | Bomb state, defuse timing and progress UI |
| [Speed graph](speed_graph.md) | Command sampling and speed history |
| [Native ESP extensions](native_esp.md) | Native ESP items and setting overrides |

Install a downloaded `.lua` file from the script manager described in
[Getting started](../getting-started.md). Each file is independent.

Open the menu and drag any part of a movable panel. The full panel is clickable,
not only the header. Panel clicks stay blocked from gameplay until the button is
released.
